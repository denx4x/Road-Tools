# Road Tools Demo

Open `Scenes/Road Tools Demo.unity` to try the sample road, terrain and props.

- `Materials` and `Textures`: editable asphalt variants and procedural fence materials.
- `Prefabs`: lamps, procedural fence and socket hub.
- `Props/Road Fence`: imported fence model, cleaned mesh, material, texture and prefab.
- `Profiles`: road profiles for this demo.
- `Terrain`: terrain data, base snapshot and terrain layers/textures.

These assets are separate copies of the package presets. Editing a demo material or prefab does not change package defaults. Scripts, Unity Splines and URP remain package dependencies.

If an earlier import contains only folders or is incomplete, use **Tools > Road Tools > Import Demo Sample** to add missing assets while preserving existing files. This does not open or replace your current scene.
