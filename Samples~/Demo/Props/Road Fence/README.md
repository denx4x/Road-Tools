# Road Fence Sample

Use `Prefabs/Road Fence.prefab` with **Props > Add Fence**, or select it as Fence Prefab in Advanced Prop Layers.

- `Models/Road_fence.fbx`: source model.
- `Models/Road Fence Clean.asset`: prepared mesh used by the prefab.
- `Materials/Road Fence Galvanized Steel.mat`: URP material.
- `Textures/Road Fence Galvanized Steel.png`: surface texture.

The prefab includes Road Fence Model settings for continuous spline deformation and terrain grounding. These sample assets are editable independently from the package defaults.
